# GCS

Aplikasi desktop GCS. Tauri 2 untuk shell desktop, React 19 + TypeScript + Vite untuk UI, Rust untuk command di `src-tauri/`.

Statusnya masih scaffold: halaman welcome bawaan Tauri dengan satu command `greet`, belum ada fitur GCS yang sebenarnya.

```bash
pnpm install
pnpm tauri dev
```

Prasyarat lengkap, dependensi sistem per OS, dan langkah build installer ada di [`../docs/installation-gcs.md`](../docs/installation-gcs.md).
