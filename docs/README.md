# Dokumentasi

Kumpulan panduan untuk repository final assignment GMAT. Setiap dokumen ditulis supaya bisa diikuti dari nol, tanpa perlu menebak langkah yang terlewat.

| Dokumen | Untuk siapa | Status |

## Kalau baru pertama kali

Baca [installation-gcs.md](installation-gcs.md) sampai bagian "Menjalankan aplikasi". Setelah `pnpm tauri dev` jalan dan jendela aplikasi terbuka, sisanya bisa eksplor sendiri.

## Konvensi penulisan

Dokumen di folder ini pakai Bahasa Indonesia. Nama perintah, path, dan istilah teknis dibiarkan dalam bahasa aslinya supaya gampang dicari: `pnpm install`, `src-tauri`, WebView, dan sejenisnya.

Kalau ada langkah yang ternyata gagal di mesin tertentu, tambahkan catatan di bagian troubleshooting dokumen terkait, bukan di README utama. Tujuannya supaya README tetap ringkas dan detail masalah menempel di panduan yang benar.
